# Servicios Digitales del CFIA

Abra index.html para ver la presentación. Para publicarla con GitHub Pages, suba index.html y la carpeta assets a la raíz del repositorio. En Settings → Pages seleccione la publicación desde la rama que contiene los archivos y la carpeta / (root).

La presentación utiliza Noir Pro y Myriad Pro cuando están instaladas. En otros equipos, el navegador emplea las alternativas del sistema.
